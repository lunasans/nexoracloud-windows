# NexoraCloud für Windows

Hier liegen nur die fertigen Setups des Windows-Clients von NexoraCloud
(unter [Releases](../../releases)). Der Quellcode liegt nicht hier.

- **NexoraCloud-Setup.exe**: installiert oder aktualisiert NexoraCloud für das
  aktuelle Windows-Konto, ohne Adminrechte.
- **NexoraCloud-Setup.exe.sha256**: SHA-256-Prüfsumme des Setups.

Installierte Clients prüfen dieses Repo selbst auf neue Versionen und bieten
das Update im Fenster an.
